Trial programming task for SPAR alignment research mentorship scheme.

gpt-shell.py allows the user to interact with models in a shell environment. The model can propose commands to be run, which are then reviewed by the user. The file also has classes allowing for the easy integration of additional models, which is demonstrated by the addition of a gpt-3.5 instance which evaluates the safety of the proposed command before the user reviews it. This was completed in ~2 hours, as directed by the brief.
